# CRAFTED LEAVES (PVT) LTD.
### The Art of Handmade Ceylon Tea & Artisanal Spices

A modern, high-performance web platform built strictly according to the official **Crafted Leaves (Pvt) Ltd.** brand document and inspired by the live presence at [`https://craftedleaves.com/`](https://craftedleaves.com/).
